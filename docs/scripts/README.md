# Script Documentation

Folder ini berisi dokumentasi terkait script-script yang digunakan dalam project.

## Penggunaan

Dokumentasi ini berguna untuk:
- Referensi penggunaan script
- Panduan maintenance
- Dokumentasi script yang sudah dibuat

## Catatan

- Folder ini untuk dokumentasi script yang sudah ada
- Script-script actual berada di folder `scripts/`
- Update dokumentasi jika ada script baru
